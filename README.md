## Patient Data Explorer

A small biomedical data analysis project developed in Python to explore patient data, perform basic statistical analysis, and visualize clinical variables. This project was created as a first step into Biomedical Data Science, Python, and specially Git/GitHub workflows. The project uses a small fictional dataset containing basic clinical variables from 10  fictional patients.


## Technologies

* Python 3.11
* Pandas
* Matplotlib
* Git
* GitHub
* Visual Studio Code
